# Notebooks

В каталоге находятся два финальных воспроизводимых ноутбука:

1. `01_dataset_preparation.ipynb` — статистика датасета, предобработка и проверка признаков.
2. `02_model_comparison.ipynb` — итоговое сравнение CNN и CRNN и анализ результатов.

Первый ноутбук импортирует рабочую предобработку из `src`. Второй дополнительно содержит
самодостаточный код исследовательских запусков: определения конфигураций, построение
подвыборок, обучение, early stopping, evaluation и перебор seed. По умолчанию тяжёлые
этапы читают сохранённые результаты; каждый этап можно пересчитать отдельным флагом.
