# Checkpoints

- `cnn_width8.pt` — CNN Width-8, representative seed 777 selected by validation metrics.
- `crnn_micro.pt` — CRNN Micro, representative seed 123 selected by validation metrics.

Конкретные checkpoint выбраны без ранжирования по test. Средние результаты в README относятся
к трём запускам каждой архитектуры, а не к одному файлу весов.
