# SoundClassifier

Классификатор пяти типов пользовательских звуков: хлопок, стук, пение, звук ложки и свист.
Проект сравнивает компактные CNN и CRNN на независимом разбиении по сессиям записи.

## Модели

- **CNN Width-8** — более быстрый инференс отдельных файлов.
- **CRNN Micro** — более высокое среднее качество в проведённом эксперименте.

Обе модели сохранены: выбор зависит от приоритета между задержкой и качеством.

## Установка

Проверенное окружение обучения: Python 3.13, PyTorch 2.11, torchaudio 2.11.

```bash
python -m venv .venv
python -m pip install -r requirements.txt
```

## Инференс

По умолчанию файл классифицируется обеими моделями:

```bash
python predict.py demo_samples/example.wav
```

Можно выбрать одну модель:

```bash
python predict.py demo_samples/example.wav --model cnn
python predict.py demo_samples/example.wav --model crnn
```

## Основные результаты

| Модель | Параметры | Test macro-F1 | Test accuracy | CPU batch=1, медиана |
|---|---:|---:|---:|---:|
| CNN Width-8 | 6 109 | 0.9576 ± 0.0215 | 0.9606 ± 0.0189 | 1.430 мс |
| CRNN Micro | 6 068 | 0.9934 ± 0.0058 | 0.9939 ± 0.0052 | 3.727 мс |

Эксперименты проводились на компьютере с AMD Ryzen 5 2600 и NVIDIA GeForce RTX 2060 Super.
В таблице приведена медиана на CPU при `batch=1`; на другом процессоре значения будут отличаться.

Среднее и стандартное отклонение качества рассчитаны по трём seed на одной фиксированной test-сессии.
Это не оценка вариативности между произвольными новыми условиями записи.
